### Selectores de idioma

Componentes profesionales de selector de idioma, diseñados para una selección de configuración regional fluida en toda tu aplicación.

| Componente                                                                                | Descripción                                                           |
| ---------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| **[Selector de idioma](/docs/components/language-switchers/language-switcher)**           | Desplegable completo con búsqueda, banderas y compatibilidad con RTL            |
| **[Selector de idioma en píldora](/docs/components/language-switchers/language-switcher-pill)** | Selector animado en estilo píldora con navegación por teclado y compatibilidad con RTL |

### Selectores de configuración regional

Elige una región y consulta los valores predeterminados de configuración regional que la acompañan, para páginas de ajustes y flujos de incorporación.

| Componente                                                          | Descripción                                                                       |
| ------------------------------------------------------------------ | --------------------------------------------------------------------------------- |
| **[Selector de configuración regional](/docs/components/locale-pickers/locale-picker)** | Selector de región con moneda, fecha, número y primer día de la semana derivados, además de búsqueda |

### Entrada de teléfono

Campo internacional para números de teléfono con selector de país y búsqueda de prefijos telefónicos.

| Componente                                              | Descripción                                                          |
| ------------------------------------------------------ | -------------------------------------------------------------------- |
| **[Entrada de teléfono](/docs/components/inputs/phone-input)** | Selector de país con banderas, prefijos telefónicos y búsqueda para 50 países |

### Navegación

Barra de navegación completa con soporte de localización integrado.

| Componente                                        | Descripción                                                              |
| ------------------------------------------------ | ------------------------------------------------------------------------ |
| **[NavBar](/docs/components/navigation/navbar)** | Navegación adaptable con selector de idioma, menú móvil, botón CTA y enlace a GitHub |

### Traducción

Vistas de traducción lado a lado para comparar y editar el texto de origen y de destino.

| Componente                                                                 | Descripción                                                      |
| ------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| **[Widget de traducción](/docs/components/translation/translation-widget)** | Panel de destino editable, diseño compatible con RTL y estilo claymorphism |

## Especificaciones técnicas

### Características principales

- **Soporte completo de TypeScript** - Seguridad de tipos completa con IntelliSense
- **Diseño adaptable** - Enfoque mobile-first con optimización por breakpoints
- **Cumplimiento de accesibilidad** - Estándares WCAG 2.1 AA con soporte para lectores de pantalla
- **Documentación completa** - Ejemplos de uso, referencia de la API y buenas prácticas

### Integración y compatibilidad

- **React 18+** con soporte para hooks
- Compatibilidad con App Router de **Next.js 13+**
- Integración con el sistema de diseño **shadcn/ui**
- Estilos **Tailwind CSS** basados en utilidades
- Compatibilidad con gestores de paquetes **npm/pnpm/yarn**
