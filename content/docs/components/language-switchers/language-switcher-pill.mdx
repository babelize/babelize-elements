## Usage

````tsx
import { LanguageSwitcherPill } from "@/components/ui/language-switcher-pill";

```mdx
```tsx
import { useState } from "react";

const locales = [
  { code: "en", label: "English", flag: "🇺🇸" },
  { code: "es", label: "Español", flag: "🇪🇸" },
  { code: "fr", label: "Français", flag: "🇫🇷" },
];

export function Example() {
  const [locale, setLocale] = useState("en");

  return (
    <LanguageSwitcherPill
      locales={locales}
      locale={locale}
      onLocaleChange={setLocale}
    />
  );
}

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `locales` | `Locale[]` | — | List of available languages. |
| `locale` | `string` | — | Controlled selected locale. |
| `defaultLocale` | `string` | First locale | Initial locale for uncontrolled usage. |
| `onLocaleChange` | `(locale: string) => void` | — | Called when the selected language changes. |
| `className` | `string` | — | Additional CSS classes for the pill. |

## Keyboard Navigation

- **Arrow Right** — Move to the next language.
- **Arrow Left** — Move to the previous language.
- **Home** — Move to the first language.
- **End** — Move to the last language.
- **Enter / Space** — Select the focused language.

## RTL Support

The component supports right-to-left languages such as Arabic, Hebrew, Persian, Urdu, Pashto, Sindhi, and Yiddish.

Locale-specific direction is applied automatically, while the active indicator follows the selected language.

```tsx
const locales = [
  { code: "en", label: "English", flag: "🇺🇸" },
  { code: "ar", label: "العربية", flag: "🇸🇦", rtl: true },
  { code: "he", label: "עברית", flag: "🇮🇱", rtl: true },
];

<LanguageSwitcherPill
  locales={locales}
  defaultLocale="en"
/>;
````
