## الاستخدام [#usage]

```tsx
"use client";

import { useState } from "react";
import { LanguageSwitcher } from "@/components/ui/language-switcher";

const locales = [{ code: "en" }, { code: "fr" }, { code: "es" }, { code: "ja" }, { code: "ar" }];

export function LocaleSwitcher() {
  const [locale, setLocale] = useState("en");

  return (
    <LanguageSwitcher
      locales={locales} // only `code` is required, labels and flags are auto-resolved
      value={locale} // omit for uncontrolled, use defaultValue instead
      onValueChange={setLocale}
      label="native" // or "english" (default)
      showFlags
    />
  );
}
```

## الخصائص [#props]

| الخاصية             | النوع                                 | مطلوب | الوصف                                                                            |
| ------------------- | ------------------------------------- | ----- | -------------------------------------------------------------------------------- |
| `locales`           | `Locale[]`                            | نعم   | مصفوفة الإعدادات المحلية المتاحة — `code` فقط مطلوب                              |
| `value`             | `string`                              | لا    | رمز الإعدادات المحلية المحدد — مرّره للتحكم في المكوّن                           |
| `defaultValue`      | `string`                              | لا    | رمز الإعدادات المحلية المحدد الأولي (الافتراضي: رمز أول إعدادات محلية)           |
| `onValueChange`     | `(code: string) => void`              | لا    | دالة استدعاء عند تغيّر الإعدادات المحلية                                         |
| `label`             | `"native" \| "english"`               | لا    | عرض التسميات باللغة الأصلية أو الإنجليزية (الافتراضي: `"english"`)               |
| `showFlags`         | `boolean`                             | لا    | إظهار أعلام emoji (الافتراضي: `false`)                                           |
| `maxHeight`         | `number \| string`                    | لا    | أقصى ارتفاع لقائمة الخيارات القابلة للتمرير (الافتراضي: `"15rem"`)               |
| `showCode`          | `boolean`                             | لا    | إظهار رمز الإعدادات المحلية بجانب كل خيار (الافتراضي: `false`)                   |
| `variant`           | `"outline" \| "ghost" \| "secondary"` | لا    | نمط الزر المُشغّل (الافتراضي: `"outline"`)                                       |
| `size`              | `"sm" \| "default" \| "lg"`           | لا    | حجم الزر المُشغّل (الافتراضي: `"default"`)                                       |
| `align`             | `"start" \| "end"`                    | لا    | الحافة التي تصطف القائمة معها في الزر المُشغّل (الافتراضي: `"start"`)            |
| `side`              | `"top" \| "bottom"`                   | لا    | الجانب المفضل للقائمة؛ يتبدّل عند عدم وجود مساحة (الافتراضي: `"bottom"`)         |
| `searchable`        | `boolean`                             | لا    | إظهار حقل البحث (الافتراضي: `true`)                                              |
| `searchPlaceholder` | `string`                              | لا    | النص النائب للبحث (الافتراضي: `"Search languages..."`)                           |
| `emptyMessage`      | `ReactNode`                           | لا    | يُعرض عندما لا يطابق البحث أي نتيجة (الافتراضي: `"No languages found."`)         |
| `labels`            | `Partial<LanguageSwitcherLabels>`     | لا    | تجاوز نصوص الواجهة الإنجليزية المدمجة (انظر أدناه)                               |
| `disabled`          | `boolean`                             | لا    | تعطيل الزر المُشغّل                                                              |
| `renderOption`      | `(locale, state) => ReactNode`        | لا    | استبدال محتوى كل صف خيار؛ يحوي `state` على `selected` و`active` و`label` و`flag` |
| `classNames`        | `LanguageSwitcherClassNames`          | لا    | أصناف لكل جزء: `trigger`، `content`، `search`، `list`، `item`، `empty`           |
| `className`         | `string`                              | لا    | أصناف CSS إضافية على الجذر                                                       |

### كائن الإعدادات المحلية [#locale-object]

| الخاصية | النوع     | الوصف                                                                 |
| ------- | --------- | --------------------------------------------------------------------- |
| `code`  | `string`  | رمز ISO 639-1 / BCP 47 (مثل `"en"`، `"fr-FR"`، `"ar-SA"`) — **مطلوب** |
| `label` | `string`  | تجاوز اسم العرض (يُحدَّد تلقائيًا من الجدول المدمج عند الحذف)         |
| `flag`  | `string`  | تجاوز علم emoji (يُكتشف تلقائيًا من الرمز عند الحذف)                  |
| `rtl`   | `boolean` | تجاوز RTL (يُكتشف تلقائيًا من الرمز عند الحذف)                        |

## أمثلة [#examples]

### مع Babelize SDK [#with-babelize-sdk]

اقرن مبدّل اللغة مع [Babelize SDK](https://docs.babelize.co/sdk) للترجمة التلقائية:

```tsx
"use client";

import { useState } from "react";
import { useRouter } from "next/navigation";
import { LanguageSwitcher } from "@/components/ui/language-switcher";
import { useBabelize } from "@babelize/sdk/react";

const locales = [
  { code: "en", label: "English", flag: "🇺🇸" },
  { code: "fr", label: "Français", flag: "🇫🇷" },
  { code: "es", label: "Español", flag: "🇪🇸" },
  { code: "de", label: "Deutsch", flag: "🇩🇪" },
  { code: "ja", label: "日本語", flag: "🇯🇵" },
  { code: "ar", label: "العربية", flag: "🇸🇦" },
];

export function LocaleSwitcher() {
  const router = useRouter();
  const { locale, setLocale } = useBabelize();

  return (
    <LanguageSwitcher
      locales={locales}
      value={locale}
      onValueChange={(code) => {
        setLocale(code);
        router.push(`/${code}`);
      }}
    />
  );
}
```

### مع react-i18next [#with-react-i18next]

```tsx
"use client";

import { useTranslation } from "react-i18next";
import { LanguageSwitcher } from "@/components/ui/language-switcher";

export function LocaleSwitcher() {
  const { i18n } = useTranslation();

  return (
    <LanguageSwitcher
      locales={[{ code: "en" }, { code: "fr" }]}
      value={i18n.language}
      onValueChange={(code) => i18n.changeLanguage(code)}
    />
  );
}
```

### تخصيص الأجزاء [#customizing-parts]

يُنسَّق المبدّل برموز سمة shadcn، فيتبع سمتك. استخدم `classNames` لإعادة تنسيق أي جزء، أو `renderOption` لتغيير ما يعرضه كل صف:

```tsx
<LanguageSwitcher
  locales={locales}
  variant="ghost"
  size="sm"
  align="end"
  classNames={{ content: "w-64", item: "py-2" }}
  renderOption={(locale, { label, flag, selected }) => (
    <>
      <span className="text-base leading-none">{flag}</span>
      <span className="flex-1">{label}</span>
      <span className="text-xs text-muted-foreground">{selected ? "Current" : locale.code}</span>
    </>
  )}
/>
```

### نصوص الواجهة المترجمة [#translated-ui-text]

تكون النصوص النائبة للبحث وحالة الفراغ وتسميات إمكانية الوصول بالإنجليزية افتراضيًا. مرّر `labels` لترجمتها — وأي مفتاح تتركه يحتفظ بقيمته الإنجليزية الافتراضية. وتظل الخاصيتان `searchPlaceholder` و`emptyMessage` تعملان، وتتغلبان على `labels` عند ضبطهما معًا.

```tsx
"use client";

import { LanguageSwitcher } from "@/components/ui/language-switcher";

export default function App() {
  return (
    <LanguageSwitcher
      locales={[{ code: "en" }, { code: "fr" }, { code: "es" }]}
      defaultValue="fr"
      label="native"
      labels={{
        searchPlaceholder: "Rechercher une langue…",
        searchLabel: "Rechercher une langue",
        clearSearch: "Effacer la recherche",
        emptyMessage: "Aucune langue trouvée.",
        listbox: "Choisir la langue",
        current: (name) => `Langue actuelle : ${name}`,
      }}
    />
  );
}
```

| المفتاح             | الافتراضي                               | يُستخدم في                           |
| ------------------- | --------------------------------------- | ------------------------------------ |
| `searchPlaceholder` | `"Search languages..."`                 | النص النائب لحقل البحث               |
| `searchLabel`       | `"Search languages"`                    | تسمية إمكانية الوصول لحقل البحث      |
| `clearSearch`       | `"Clear search"`                        | تسمية إمكانية الوصول لزر المسح       |
| `emptyMessage`      | `"No languages found."`                 | يُعرض عند عدم وجود تطابق             |
| `listbox`           | `"Select language"`                     | تسمية إمكانية الوصول لقائمة الخيارات |
| `current`           | `(name) => "Current language: " + name` | تسمية إمكانية الوصول للزر المُشغّل   |

## دعم لوحة المفاتيح [#keyboard-support]

تتبع النافذة المنبثقة نمط combobox في WAI-ARIA: يبقى التركيز في حقل البحث، الذي يُعرض كـ `role="combobox"`، ويُعلَن عن الخيار المميّز عبر `aria-activedescendant`.

| المفتاح                         | الإجراء                                                        |
| ------------------------------- | -------------------------------------------------------------- |
| `Enter`، `Space`، أو النقر      | افتح النافذة المنبثقة من الزر المُشغّل                         |
| `ArrowDown` / `ArrowUp` (مغلقة) | افتح مع تمييز أول إعدادات محلية / آخرها                        |
| `ArrowDown` / `ArrowUp`         | انقل التمييز، مع الالتفاف عند الطرفين                          |
| `Home` / `End`                  | مميّز أول إعدادات محلية / آخرها                                |
| `Enter`                         | اختر الإعدادات المحلية المميّزة وأعد التركيز إلى الزر المُشغّل |
| `Escape`                        | أغلق النافذة المنبثقة وأعد التركيز إلى الزر المُشغّل           |
| الكتابة                         | صفِّ حسب الاسم أو الرمز؛ يبدأ التمييز من الأعلى مجددًا         |

يبقى التمييز على الصف الذي ظهر فيه عند فتح القائمة — وتتمرر القائمة أسفله، كالقائمة الأصلية — ولا تتمرر الصفحة نفسها أبدًا. مرّر `maxHeight` لتغيير ارتفاع القائمة قبل أن تبدأ بالتمرير.

## الميزات [#features]

- **بلا إعداد** — مرّر الرموز فقط، وتُحدَّد التسميات والأعلام تلقائيًا
- **قائمة منسدلة مع بحث** — صفِّ الإعدادات المحلية حسب الاسم أو الرمز
- **يراعي RTL** — يكتشف الإعدادات المحلية من نوع RTL (ar وhe وfa وur) ويعدّل التخطيط
- **متاح عبر لوحة المفاتيح** — التنقل بمفاتيح الأسهم وHome / End وEnter وEscape
- **تسميات ARIA** — حقل البحث `role="combobox"` مع `aria-activedescendant`، إضافةً إلى `aria-expanded` و`aria-haspopup` و`aria-selected`
- **الوضع الداكن** — مبني بـ Tailwind CSS ومتوافق مع الوضع الداكن
- **مستقل عن المكتبات** — يعمل مع أي إعداد i18n عبر دالة الاستدعاء
