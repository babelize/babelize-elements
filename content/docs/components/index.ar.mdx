### مبدّلات اللغة

مكوّنات احترافية لمبدّل اللغة مصممة لتحديد الإعدادات المحلية بسلاسة في جميع أجزاء تطبيقك.

| المكوّن                                                                                | الوصف                                                           |
| ---------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| **[مبدّل اللغة](/docs/components/language-switchers/language-switcher)**           | قائمة منسدلة متكاملة الميزات مع البحث والأعلام ودعم RTL            |
| **[كبسولة مبدّل اللغة](/docs/components/language-switchers/language-switcher-pill)** | أداة اختيار متحركة بأسلوب الكبسولة مع التنقل بلوحة المفاتيح ودعم RTL |

### منتقيات الإعدادات المحلية

اختر منطقة واطّلع على القيم الافتراضية للإعدادات المحلية المرتبطة بها، لصفحات الإعدادات وتدفقات الإعداد الأولي.

| المكوّن                                                          | الوصف                                                                       |
| ------------------------------------------------------------------ | --------------------------------------------------------------------------------- |
| **[منتقي الإعدادات المحلية](/docs/components/locale-pickers/locale-picker)** | منتقي المناطق مع القيم الافتراضية المشتقة للعملة والتاريخ والأرقام وبداية الأسبوع، مع البحث |

### حقل إدخال الهاتف

حقل إدخال أرقام الهواتف الدولية مع محدّد الدولة والبحث عن رمز الاتصال.

| المكوّن                                              | الوصف                                                          |
| ------------------------------------------------------ | -------------------------------------------------------------------- |
| **[حقل إدخال الهاتف](/docs/components/inputs/phone-input)** | محدّد الدولة مع الأعلام ورموز الاتصال والبحث في 50 دولة |

### التنقل

شريط تنقل متكامل الميزات مع دعم مدمج للتوطين.

| المكوّن                                        | الوصف                                                              |
| ------------------------------------------------ | ------------------------------------------------------------------------ |
| **[NavBar](/docs/components/navigation/navbar)** | شريط تنقل متجاوب مع محدّد اللغة وقائمة الجوال وزر دعوة لاتخاذ إجراء ورابط GitHub |

### الترجمة

عروض ترجمة جنبًا إلى جنب لمقارنة النص المصدر والنص الهدف وتحريرهما.

| المكوّن                                                                 | الوصف                                                      |
| ------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| **[أداة الترجمة](/docs/components/translation/translation-widget)** | لوحة هدف قابلة للتحرير، وتخطيط يراعي RTL، وتنسيق claymorphism |

## المواصفات التقنية

### الميزات الأساسية

- **دعم TypeScript كامل** - أمان أنواع شامل مع IntelliSense
- **تصميم متجاوب** - نهج يبدأ بالجوال مع تحسين نقاط الكسر
- **الامتثال لإمكانية الوصول** - معايير WCAG 2.1 AA مع دعم قارئات الشاشة
- **توثيق شامل** - أمثلة الاستخدام ومرجع API وأفضل الممارسات

### التكامل والتوافق

- **React 18+** مع دعم hooks
- **Next.js 13+** مع توافق App Router
- تكامل نظام التصميم **shadcn/ui**
- تنسيق **Tailwind CSS** القائم على الأدوات المساعدة
- دعم مدير الحزم **npm/pnpm/yarn**
