Every Babelize component uses CSS custom properties for colors, borders, and surfaces. Override them in your `globals.css` to restyle the entire library without touching component code.

## How It Works

Components reference tokens like `var(--primary)`, `var(--background)`, `var(--border)`. Change the values, every component updates.

```css title="src/app/globals.css"
:root {
  --background: #ffffff;
  --foreground: #111111;
  --primary: #00bd7d;
  --primary-foreground: #ffffff;
  --card: #f9f9f9;
  --border: rgba(0, 0, 0, 0.08);
  /* ... more tokens */
}

.dark {
  --background: #000000;
  --foreground: #ededed;
  --primary: #00bd7d;
  --card: #0d0d0d;
  --border: rgba(255, 255, 255, 0.08);
}
```

## Dark Mode + Light Mode

Every component supports both modes out of the box. Toggle the `dark` class on `<html>` to switch:

```tsx
"use client";

import { useTheme } from "next-themes";

export function ThemeToggle() {
  const { theme, setTheme } = useTheme();

  return (
    <button onClick={() => setTheme(theme === "dark" ? "light" : "dark")}>
      {theme === "dark" ? "Light" : "Dark"}
    </button>
  );
}
```

## CSS Variables Reference

All tokens used by Babelize components:

| Token | Purpose | Example (dark) |
|-------|---------|----------------|
| `--background` | Page background | `#000000` |
| `--foreground` | Body text | `#ededed` |
| `--primary` | Buttons, links, accents | `#00bd7d` |
| `--primary-foreground` | Text on primary | `#ffffff` |
| `--secondary` | Secondary buttons | `#f0fdf4` |
| `--secondary-foreground` | Text on secondary | `#00714b` |
| `--card` | Card surfaces | `#0d0d0d` |
| `--card-foreground` | Text on cards | `#ededed` |
| `--accent` | Hover states | `#dcfce7` |
| `--accent-foreground` | Text on accent | `#004b32` |
| `--muted` | Subtle backgrounds | `#131313` |
| `--muted-foreground` | Muted text | `#8a8a8a` |
| `--border` | Borders | `rgba(255,255,255,0.08)` |
| `--input` | Input borders | `rgba(255,255,255,0.06)` |
| `--destructive` | Error states | `#dc2626` |

## Creating Your Own Theme

### Step 1: Pick a primary color

Choose a hex color for your brand. Convert to HSL or keep as hex.

### Step 2: Generate light and dark variants

Light mode: lighter backgrounds, darker text.
Dark mode: darker backgrounds, lighter text.

### Step 3: Add to globals.css

```css title="src/app/globals.css"
:root {
  --primary: #your-hex;
  --primary-foreground: #ffffff;
  /* derive other tokens from your primary */
}

.dark {
  --primary: #your-lighter-hex;
  --primary-foreground: #your-dark-hex;
}
```

### Step 4: Override at component level

Each component is owned by you, so you can edit Tailwind classes directly:

```tsx
// Change border radius for a specific component
<div className="rounded-full border ...">

// Change the button style
<button className="bg-gradient-to-r from-blue-500 to-purple-500 ...">
```

## Component-Level Overrides

Because every component lives in your repo, you can customize anything:

```tsx title="src/registry/components/language-switcher.tsx"
// Before
<button className="rounded-lg border border-white/10 bg-white/5 ...">

// After — change to pill shape, add shadow
<button className="rounded-full border border-black/20 bg-white shadow-lg ...">
```

No design tokens needed. Just edit the file.

## Tips

- Start with the default Emerald theme, then tweak `--primary` to match your brand
- Use `rgba()` for borders to get smooth alpha blending
- The `--muted` token is perfect for hover states and subtle backgrounds
- Test both light and dark mode — components respect the `.dark` class automatically
- Copy-paste components mean zero lock-in, change anything you want
