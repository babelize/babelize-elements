## Babelize Elements [#babelize-elements]

Babelize Elements は React および Tailwind CSS 向けの**ローカライゼーション UI コンポーネント**を集めた**オープンソース**ライブラリです。

ローカライズされたアプリに必要な基本部品（言語スイッチャー、ロケールピッカー、翻訳ウィジェット、RTL に対応したレイアウトなど）を集めた、コミュニティの拠点です。Babelize コミュニティによって、Babelize コミュニティのために作られています。

## Elements を選ぶ理由 [#why-elements]

ローカライズされたアプリを作るとは、どのプロジェクトでも同じ UI の作業を繰り返すことです。言語のドロップダウン、ロケールに応じた日付表示、RTL に安全なナビゲーションなどです。Elements は、こうした作業を共有可能なオープンソースのツールボックスにまとめます。

- **簡単なインストール** — ライブラリ全体は `npm install @babelize/elements`、コンポーネントは `npx shadcn@latest add @babelize/<component>` を使って1つずつインストールできます。
- **ローカライゼーション優先** — すべてのコンポーネントに、複数形、RTL、ロケールデータのサポートが組み込まれています。
- **アクセシブル** — キーボード対応、ARIA ラベル、WCAG を考慮したマークアップを標準で備えています。
- **オープンソース** — MIT ライセンスで、永久に無料です。あなたのようなコントリビューターによって作られています。

## 内容 [#whats-inside]

現在このサイトでは、はじめにガイドを公開しています。個々のコンポーネントは、GitHub の Issue を通じて**コミュニティから提供されています**。未解決のIssueを選び、コンポーネントを作成し、pull request を作成すると、ここで公開されます。
