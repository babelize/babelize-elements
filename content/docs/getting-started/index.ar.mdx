## Babelize Elements

Babelize Elements هي **مكتبة مفتوحة المصدر** من **مكوّنات واجهات التوطين** لـ React وTailwind CSS.

إنها المنزل المجتمعي للبنى الأساسية التي يحتاجها كل تطبيق مُعرّب، مثل مبدّلات اللغة، ومنتقيات الإعدادات المحلية، وأدوات الترجمة، والتخطيطات المدركة لـ RTL، وغيرها. بناها مجتمع Babelize، من أجل مجتمع Babelize.

## لماذا Elements؟

بناء تطبيق مُعرّب يعني تكرار العمل نفسه في كل مشروع: قائمة لغات هنا، وتاريخ يراعي اللغة المحلية هناك، وتنقل آمن لـ RTL في كل مكان. تحوّل Elements هذا العمل إلى صندوق أدوات مشترك ومفتوح المصدر.

- **سهلة التثبيت** — `npm install @babelize/elements` للمكتبة الكاملة، أو ثبّت المكوّنات واحدًا تلو الآخر عبر `npx shadcn@latest add @babelize/<component>`.
- **التوطين أولًا** — كل مكوّن يأتي مع دعم مدمج للجمع وRTL وبيانات اللغات المحلية.
- **قابلة للوصول** — دعم لوحة المفاتيح، وتسميات ARIA، وتنسيق يراعي WCAG جاهز من البداية.
- **مفتوحة المصدر** — برخصة MIT، ومجانية دائمًا، ويبنيها مساهمون مثلك.

## ما الذي يتضمنه؟

يقدّم هذا الموقع حاليًا دليل البدء. أما المكوّنات الفردية فيساهم بها **المجتمع** عبر مشكلات GitHub. اختر مشكلة مفتوحة، وابنِ المكوّن، وافتح pull request لتراه مباشرةً هنا.
