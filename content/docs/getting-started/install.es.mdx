Babelize Elements encaja en cualquier proyecto de React + Tailwind CSS: Next.js, Vite, Remix o cualquier otra herramienta que empaquete React. El paquete incluye tipos de TypeScript y compilaciones ESM y CJS. Las dependencias en tiempo de ejecución son pocas y estándar en el ecosistema de shadcn: `motion` para animaciones y `lucide-react` para iconos.

## Gestor de paquetes

Instala la biblioteca completa con tu gestor de paquetes preferido:

<Tabs items={["npm", "pnpm", "yarn", "bun"]}>
  <Tab value="npm">

```bash
npm install @babelize/elements
```

  </Tab>
  <Tab value="pnpm">

```bash
pnpm add @babelize/elements
```

  </Tab>
  <Tab value="yarn">

```bash
yarn add @babelize/elements
```

  </Tab>
  <Tab value="bun">

```bash
bun add @babelize/elements
```

  </Tab>
</Tabs>

## Indícale a Tailwind el paquete

Tailwind solo genera las clases que encuentra en tus archivos fuente, y no analiza `node_modules`. Sin este paso, los componentes se muestran **sin estilos**.

Indica a Tailwind el paquete una sola vez:

<Tabs items={["Tailwind v4", "Tailwind v3"]}>
  <Tab value="Tailwind v4">

Añade una línea `@source` al archivo CSS que importa Tailwind, con la ruta relativa a ese archivo:

```css title="app/globals.css"
@import "tailwindcss";
@source "../node_modules/@babelize/elements/dist";
```

  </Tab>
  <Tab value="Tailwind v3">

Añade el paquete a `content` en tu configuración de Tailwind:

```js title="tailwind.config.js"
module.exports = {
  content: ["./src/**/*.{ts,tsx}", "./node_modules/@babelize/elements/dist/**/*.js"],
};
```

  </Tab>
</Tabs>

Este paso solo es necesario para el paquete npm. Los componentes instalados con la [CLI de shadcn](/docs/getting-started/shadcn-cli) viven en tu propio árbol de código fuente, que Tailwind ya analiza.

## Tokens de tema

Los componentes se estilizan con tokens semánticos de [shadcn/ui](https://ui.shadcn.com/docs/theming), como `bg-popover`, `text-muted-foreground`, `ring-ring` y demás, para que adopten automáticamente el tema, el radio y el modo oscuro de tu aplicación.

**¿Ya usas shadcn/ui?** No hay nada que hacer: `shadcn init` ya definió los tokens.

**¿No usas shadcn/ui?** Añade los tokens una sola vez al archivo CSS que importa Tailwind. Este es el tema neutro de shadcn; cambia cualquier valor para que coincida con tu marca.

En Tailwind v3, asigna las mismas variables bajo `theme.extend.colors` en `tailwind.config.js`, como en la [guía de shadcn para v3](https://v3.shadcn.com/docs/theming). Los componentes están diseñados para Tailwind v4; en v3 funcionan, pero algunas utilidades exclusivas de v4 (como `shadow-xs`) no tienen ningún efecto.

Todos los componentes también aceptan una prop `classNames` para sobrescribir estilos por parte, así puedes cambiar el estilo de cualquier parte sin bifurcar el código fuente.

## Instala componentes individuales

¿Prefieres instalar componentes uno a uno, directamente en tu código? Usa la [CLI de shadcn](/docs/getting-started/shadcn-cli):

```bash
npx shadcn@latest add @babelize/language-switcher
```

O usa la CLI que viene incluida en el paquete:

```bash
npx @babelize/elements add language-switcher
```

En cualquier caso, el componente (junto con su utilidad `cn` y sus dependencias) se escribe en tu directorio `components/ui/`, y a partir de ese momento el código es tuyo.

## Requisitos previos

| Dependencia   | Versión mínima |
| ------------ | --------------- |
| React        | `>=18`          |
| React DOM    | `>=18`          |
| Tailwind CSS | `>=3`           |
| Node.js      | `>=20`          |

## Verifica la instalación

Importa un componente para confirmar que todo está bien conectado:

```tsx
import { LanguageSwitcher } from "@babelize/elements";

export function App() {
  return (
    <LanguageSwitcher
      locales={[{ code: "en" }, { code: "fr" }, { code: "es" }]}
      defaultValue="en"
      onValueChange={(code) => console.log("changed to", code)}
    />
  );
}
```

Todos los componentes priorizan TypeScript, exportan su propia interfaz de props y funcionan con tu configuración existente de `next-intl`, `react-i18next` o i18n personalizada.
