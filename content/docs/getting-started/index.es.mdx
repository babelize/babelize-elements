## Babelize Elements

Babelize Elements es una **biblioteca de código abierto** de **componentes de interfaz de localización** para React y Tailwind CSS.

Es el hogar comunitario de los bloques básicos que toda aplicación localizada necesita: selectores de idioma, selectores de configuración regional, widgets de traducción, diseños compatibles con RTL y mucho más. Creado por la comunidad de Babelize, para la comunidad de Babelize.

## ¿Por qué Elements?

Crear una aplicación localizada implica repetir el mismo trabajo de interfaz en cada proyecto: un desplegable de idiomas aquí, una fecha adaptada a la configuración regional allí, una navegación segura para RTL en todas partes. Elements convierte ese trabajo en una caja de herramientas compartida y de código abierto.

- **Fácil de instalar** — `npm install @babelize/elements` para la biblioteca completa, o instala componentes uno a uno con `npx shadcn@latest add @babelize/<component>`.
- **Localización primero** — cada componente incluye de serie soporte para pluralización, RTL y datos de configuración regional.
- **Accesible** — soporte de teclado, etiquetas ARIA y marcado compatible con WCAG desde el primer momento.
- **Código abierto** — con licencia MIT, gratuito para siempre y creado por colaboradores como tú.

## Qué incluye

Este sitio incluye actualmente la guía de primeros pasos. Los componentes individuales son **aportados por la comunidad** a través de issues de GitHub: elige un issue abierto, construye el componente y abre un pull request para verlo publicado aquí.
