# ShadCN CLI 3.0 Integration Guide

We are currently working on a seamless integration with ShadCN CLI 3.0 that will allow you to add Babelize Elements directly from your terminal.

## Coming Soon

In the near future, you will be able to run a simple command like:

```bash
npx shadcn-ui@latest add https://babelize-elements.com/r/language-switcher
```

This will automatically configure the component and its dependencies inside your project. 

Stay tuned for more updates!
